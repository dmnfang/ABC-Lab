# ABC Lab

Combined classroom hub for the alphabet apps.

## Included
- `apps/abc-remix/` — ABC Remix v39
- `apps/alphabet-jumble/` — Alphabet Jumble MVP 23
- `apps/abc-trail/` — reserved for the future ABC Trail build

Open `index.html` with a local server (for example VS Code Live Server). The hub links directly to each app using relative paths.
